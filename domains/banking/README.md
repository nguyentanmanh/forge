# Banking — Kiến thức ngành có thể tái sử dụng

Chỉ dùng tri thức công khai hoặc nội dung được phép sử dụng. Không đưa cấu hình, quy trình nội bộ hoặc dữ liệu khách hàng lên FORGE.

## Các chủ đề đề xuất
- Core Banking: account, ledger, posting, settlement, reconciliation.
- Payments: inward/outward, clearing, returns, cut-off.
- Open Banking: consent, client authentication, API contract, audit.
- Risk & Controls: AML/KYC ở mức nguyên lý, bảo vệ dữ liệu.
