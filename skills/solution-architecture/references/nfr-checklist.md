# NFR Checklist

- Performance: throughput profile, p95/p99, concurrency, saturation, load burst.
- Availability: SLO, redundancy, graceful degradation, failover assumptions.
- Data: ownership, integrity, retention, recovery, backup, RPO/RTO.
- Security: authentication, authorization, trust boundary, key management, secrets, PII.
- Reliability: timeouts, retries, circuit breakers, idempotency, dedup, ordering.
- Operations: logs, metrics, traces, alerting, runbook, operational ownership.
- Delivery: backward compatibility, zero-downtime strategy, rollback, migration.
- Governance: approvals, auditability, standards, cost, vendor constraints.

Chỉ ghi target có evidence hoặc nêu rõ là target được đề xuất.
