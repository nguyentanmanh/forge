# FORGE Profiles — Chế độ làm việc

**Profiles** mô tả tiêu chuẩn đầu ra và phạm vi chuyên môn. **Perspectives** là góc nhìn nhấn mạnh khi review/thực hiện. **Skills** là workflow dùng chung; **Knowledge** là dữ liệu/tham khảo.

## Danh sách
- `software-engineering/PROFILE.md` — kỹ thuật phần mềm, với các perspectives Backend / Solution Architecture / Technical Leadership.
- `business-analysis/PROFILE.md` — nghiệp vụ và yêu cầu.
- `marketing/PROFILE.md` — nghiên cứu, chiến lược và đo lường tiếp thị.

## Routing
1. Xác định nhiệm vụ và project hiện tại.
2. Chỉ đọc Profile nếu cần tiêu chuẩn chuyên môn; với technical task mặc định `software-engineering`.
3. Chỉ chọn 1 perspective chính khi cần; không load cả ba mặc định.
4. Chọn Skill theo mô tả `name`/`description`, không theo danh sách của Profile.
5. Đọc Knowledge liên quan theo nhu cầu và quyền truy cập.

> `PROFILE.md` không phải tính năng Codex native; `AGENTS.md` chỉ dẫn đọc các file này và quyền sandbox vẫn quyết định truy cập.
