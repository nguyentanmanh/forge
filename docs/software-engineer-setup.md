# Thiết lập Profile Software Engineer

1. Review `profiles/software-engineering/PROFILE.md`, các phần cá nhân hóa và ba góc nhìn trong `perspectives/`.
2. Đăng ký các Global Skills cần sử dụng bằng script tại `../../../scripts/install-codex.sh`.
3. Từ phiên Codex mới, gọi `$solution-architecture` hoặc `$code-review`.
4. Mở một project và thực hiện test tại `../../../docs/verification.md`.

> Profile không tự bật; global/project instructions phải điều hướng để sử dụng khi cần.
