# FORGE — Intelligence Foundry

Git repository cá nhân cho Identity, Profiles, Domains, Knowledge, Skills, Templates và Career. Mọi rule phải có chủ quản rõ; không copy thông tin tổ chức.

## Phạm vi
- `AGENTS.md`: quy tắc chung, ngắn gọn.
- `identity/`: style bền vững.
- `profiles/`: expectation theo profile.
- `skills/`: workflow có trigger.
- `domains/`: tri thức ngành công khai.
- `career/`: kinh nghiệm cá nhân đã xác minh và được phép ghi.

## Skills
Chỉ đăng ký skill thực sự dùng. Danh mục trong `skills/` không tự động được Codex phát hiện cho đến khi được cài hoặc link ở nơi hỗ trợ.
